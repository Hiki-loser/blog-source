## 如何创建新文章

1. 复制此文件到同目录
2. 修改文件名为您的文章标题（如 `my-new-post.md`）
3. 修改 front-matter 中的 `title`、`categories`、`tags`、`description`
4. 编写正文内容
5. 使用 `hexo new post "文章标题"` 创建新文章，或直接创建 markdown 文件
