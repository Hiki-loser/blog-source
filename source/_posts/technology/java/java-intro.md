# Java 分类导读

欢迎来到 Java 分类 👋

这是一篇分类封面文章，用来快速了解本分类的内容结构，并帮助你按路线阅读。

## 这个分类会持续更新什么

- Java 语法与核心 API
- 面向对象与设计原则
- 并发编程与线程模型
- 常见框架与工程化实践

## 推荐阅读路径

1. 先看语言基础与语法题
2. 再看集合、IO、反射等核心模块
3. 然后进入并发、JVM 与性能优化
4. 最后补齐项目实战与常见面试题

## 学习目标

通过系统学习 Java 语言的基础知识、核心 API、并发编程和工程实践，掌握 Java 开发的核心技能，为后续深入学习框架和项目实战打下坚实的基础。
