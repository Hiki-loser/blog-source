# Java 分类导读

欢迎来到 Java 分类 👋

这是一篇分类封面文章，用来快速了解本分类的内容结构，并帮助你按路线阅读。

## 这个分类会持续更新什么

- Java 语法与核心 API
- 面向对象与设计原则
- 并发编程与线程模型
- 常见框架与工程化实践

## 推荐阅读路径

1. 先看语言基础与语法题
2. 再看集合、IO、反射等核心模块
3. 然后进入并发、JVM 与性能优化
4. 最后补齐项目实战与常见面试题

## 学习目标

在这个分类里，我会把每篇文章写成“可复习、可实践、可迁移”的形式，尽量做到：

- 讲清原理，不只记结论
- 给出可运行的最小示例
- 补充常见误区与排查思路

如果你是第一次来，建议先从日期最新的 `-intro` 文章进入，再顺着分类页继续阅读。
