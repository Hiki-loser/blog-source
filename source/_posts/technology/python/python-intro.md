# Python 分类导读

欢迎来到 Python 分类 🐍

这是一篇分类封面文章，用来帮助你快速定位 Python 学习内容。

## 这个分类在写什么

- 基础语法：变量、流程控制、函数与作用域
- 数据结构：列表、字典、集合、元组，以及各自的适用场景
- 常用库：标准库中的高频模块，以及第三方生态的选型思路
- 工程实践：虚拟环境与依赖管理、代码组织、打包与发布

后续还会逐步补充：

- 面向对象与常用设计模式在 Python 中的写法
- 迭代器、生成器与装饰器
- 异步编程（asyncio）
- 类型标注与静态检查
- 测试与调试

## 建议阅读顺序

1. 先掌握基础语法与数据结构，把「用 Python 表达逻辑」变成本能
2. 再熟悉标准库里最常用的那部分，很多轮子不必自己造
3. 然后进入工程实践：环境管理、依赖锁定、项目结构
4. 最后按需深入异步、类型标注与性能优化

## 一点建议

Python 的入门门槛低，但「能跑」和「写得好」之间距离不小。初学阶段值得刻意练习两件事：

- **优先使用内置类型和标准库**，而不是手写循环和临时结构；
- **把依赖显式声明出来**（`pyproject.toml` + 锁文件），别让环境成为以后的重建障碍。
